# Mobile Systems - Project 1: Hello World

A simple Android application developed for the **Mobile Systems** course at **Białystok University of Technology**.

## About the project

This is our first Android application. It displays a **Hello World** heading, the course and project name, and a bordered section identifying both students.

The interface is intentionally simple and was developed using **Jetpack Compose**.

## Technologies

- Kotlin
- Jetpack Compose
- Android Studio
- Android SDK

## How to run

1. Clone this repository or download it as a ZIP file.
2. Open the project folder in **Android Studio**.
3. Allow Android Studio to complete the Gradle sync.
4. Start an Android emulator or connect an Android device.
5. Select the **app** run configuration and click **Run**.
